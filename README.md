# ishopgold — Telegram-бот для продажи голды Standoff 2

Бот на **aiogram 3** + **SQLite**. Работает на ПК, в Termux и на **Railway**.

## Как проходит сделка

Игра не умеет переводить голду напрямую — только через Рынок (скин выставляют за цену, покупатель лота платит голдой, владелец лота получает голду минус комиссию). Бот автоматизирует именно эту схему:

1. Покупатель выбирает готовый пакет **или вводит своё количество голды** — цена считается по ступеням курса.
2. Бот выдаёт реквизиты и **точную цену лота** (с учётом комиссии Рынка).
3. Покупатель платит и присылает чек → заявка уходит админам («💳 проверить оплату»).
4. Админ сверяет деньги в банке и жмёт **«✅ Оплата пришла»**.
5. Бот объясняет покупателю, что делать: выставить любой недорогой скин **ровно за N G** и прислать **скриншот лота**.
6. Скриншот приходит админам («🎯 выдать голду») вместе с ожидаемой ценой лота.
7. Админ находит лот в игре, выкупает его и жмёт **«✅ Голда передана»**. Если лот не найден или цена не та — **«🔄 Нужен новый скриншот»**.
8. Покупатель подтверждает получение («✅ Всё получил» / «⚠️ Голда не пришла» — во втором случае админам уходит уведомление).

**Формула цены лота:** `цена лота = голда / (1 − комиссия)`. При комиссии 20%: чтобы покупатель получил 100 G, лот ставится за 125 G.
⚠️ Учтите это в курсе: выкупая лот за 125 G, вы тратите на 25% больше голды, чем получает покупатель.
Размер комиссии — в «⚙ Настройки → Комиссия Рынка» (в источниках попадаются и 10%, и 20%; сверьте по игре).

## Что умеет бот

**Покупатель:** каталог, 📈 курс по ступеням (`/rate`), калькулятор своего количества, «Мои заказы», поддержка. Пока есть незавершённый заказ, новый оформить нельзя. Заказ без чека автоматически отменяется через N минут (по умолчанию 30).

**Админ (`/admin`):**
- 🧾 Заявки — оплата и выдача голды (два вида карточек).
- 📈 Курс голды — ступени «от N голды — X ₽ за 100 G». Бот показывает время обновления курса.
- 📦 Товары — готовые пакеты.
- 📊 Статистика, 📢 Рассылка.
- Только главный админ: 👥 администраторы, ⚙ настройки (карта, комиссия, лимиты заказа, автоотмена), 💾 бэкап базы.
- `/ban ID` и `/unban ID`.

**Надёжность:** заявку не смогут обработать дважды два админа; сообщения переживают перезапуск бота (состояние заказа хранится в базе); ники с символами `<` `>` `&` не ломают сообщения; необязательный лог выполненных сделок в отдельный чат (`LOG_CHAT_ID`).

## Первичная настройка (после запуска)

1. `/start`, затем `/admin`.
2. **⚙ Настройки** — номер карты, банк, получатель, комиссия Рынка, юзернейм поддержки.
3. **📈 Курс голды → ➕** — отправьте, например, `100 80`, потом `1000 75`, `3000 70`. Курс по умолчанию **не задан** — цены назначаете вы.
4. По желанию **📦 Товары** — готовые пакеты.

## Деплой на Railway

Бот работает через polling, поэтому ему **не нужен ни домен, ни порт** — только постоянно запущенный процесс.

1. **Токен и ID.** В [@BotFather](https://t.me/BotFather) → `/newbot` → сохраните токен. Свой Telegram ID узнайте у `@userinfobot`.
2. **GitHub.** Создайте **приватный** репозиторий и загрузите в него содержимое папки проекта (`.env` и `*.db` в `.gitignore` уже исключены — токен в репозиторий попасть не должен).
3. **Проект в Railway.** [railway.com](https://railway.com) → **New Project → Deploy from GitHub repo** → выберите репозиторий. Файл `railway.json` уже задаёт команду запуска `python main.py`.
4. **Переменные.** Сервис → вкладка **Variables** → добавьте:
   - `BOT_TOKEN` — токен от BotFather
   - `MAIN_ADMIN_ID` — ваш Telegram ID
   - `LOG_CHAT_ID` — необязательно, ID чата для лога сделок
5. **Volume (обязательно!).** Файловая система контейнера сбрасывается при каждом деплое, и без Volume база (заказы, курс, настройки) пропадёт. Правый клик по холсту проекта (или `⌘K` / `Ctrl+K`) → **Volume** → выберите сервис бота → путь монтирования **`/data`**. Путь к базе бот возьмёт сам из переменной `RAILWAY_VOLUME_MOUNT_PATH`, которую Railway выставляет автоматически.
6. **Проверьте настройки сервиса:** одна реплика (две копии будут конфликтовать за обновления), режим Serverless/App Sleeping выключен — иначе бот «заснёт».
7. **Deploy** и откройте **Deployments → View logs**: должна появиться строка «Бот запущен и слушает обновления…». Если не задан Volume, бот сам напишет главному админу предупреждение.
8. Напишите боту `/start`. Дальнейшие обновления: `git push` → Railway задеплоит сам.

**Бэкапы:** «🛠 Админ-панель → 💾 Бэкап базы» присылает актуальный файл базы. Делайте это регулярно.

**Без GitHub:** установите [Railway CLI](https://docs.railway.com/cli), в папке проекта выполните `railway login`, `railway init`, `railway up`, затем добавьте переменные и Volume, как выше.

## Локальный запуск

```bash
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env            # впишите BOT_TOKEN и MAIN_ADMIN_ID
python main.py
```

## Структура

```
main.py          запуск, автоотмена зависших заказов, фильтр забаненных
config.py        переменные окружения, путь к базе
pricing.py       расчёт цены по ступеням и цены лота (без Telegram — легко тестировать)
database.py      SQLite: заказы со строгими переходами статусов, курс, настройки
keyboards.py     клавиатуры
utils.py         подписи заявок, инструкция по лоту, безопасные отправка/редактирование
handlers/user.py   сценарии покупателя
handlers/admin.py  админ-панель
railway.json       команда запуска для Railway
```

## Важно

- Никогда не публикуйте `.env` и токен бота.
- Скриншот чека можно подделать — подтверждайте оплату по факту поступления денег в банке.
- Перед выкупом лота сверяйте в игре цену с указанной в заявке.
- Выдача голды через Рынок может противоречить правилам игры — оцените этот риск для своего бизнеса самостоятельно.
